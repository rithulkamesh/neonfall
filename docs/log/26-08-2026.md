### Evening -- Uniforms + a real camera (tutorial 6, engine-shaped)

Went through https://sotrh.github.io/learn-wgpu/beginner/tutorial6-uniforms/ but didn't dump it all into one mega-`State` like the tutorial. Split it the way an actual engine would:

- `neon-engine`: owns `Camera` (eye/target/up/aspect/fovy/near/far), builds the view-proj matrix with glam (DirectX perspective, so no OpenGL→WGPU hack matrix).
- `neon-renderer`: owns `CameraUniform`, the uniform buffer, bind group layout, and `NFState::set_view_proj(Mat4)`. Engine never touches wgpu buffers; renderer never knows what a camera is.
- Each `RedrawRequested`: engine does `state.set_view_proj(camera.build_view_projection_matrix())`, then `render()`. Pipeline takes the camera bind-group layout; shader uses `@group(0) @binding(0)`.

got rodded a few times on the way: referenced `camera_bind_group_layout` in `Pipeline::new` before it existed (pass it in), copied tutorial `config.width` when we only have a `Vec2 size`, copied `@group(1)` / texcoords from the tutorial when we still only have colors on group 0, and — the disappearing pentagon — multiplied `view * proj` instead of `proj * view`.
